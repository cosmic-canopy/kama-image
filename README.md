# @kama/image

Image codecs for [kama](https://kama-lang.org), on every target: decoding and encoding PNG first, then the formats
renderers and tools read. It names no engine and needs no GPU, so a tool, a server or a renderer can use it.

**Status: not built.** Its design is decided in part, and PNG comes first ([ROADMAP.md](ROADMAP.md)); `src/image.kama` is still `kama seed`'s placeholder.
